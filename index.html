Guia de conexion
1Crear proyecto en Firebasev
Ve a console.firebase.google.com -- crea proyecto alpha-producciones
2Registrar app Web y copiar firebaseConfigv
Icono </> Web -- nombre: alpha-cotizador -- copia el bloque firebaseConfig
const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "tu-app.firebaseapp.com", databaseURL: "https://tu-app-default-rtdb.firebaseio.com", projectId: "tu-app", ... };
3Activar Realtime Databasev
Compilacion -- Realtime Database -- "Crear base de datos" -- Modo prueba -- Habilitar

Copia la URL (https://tu-app-default-rtdb.firebaseio.com) -- es necesaria en databaseURL

4Pegar config y conectarv
Clic en "Configurar Firebase" arriba -- pega el config -- clic Conectar

Sin email ni contrasena -- conexion directa
