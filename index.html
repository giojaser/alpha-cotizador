📋 GUÍA PASO A PASO — CONECTAR A FIREBASE
1 Crear proyecto en Firebase ▼

Ve a console.firebase.google.com e inicia sesión con tu cuenta Google.

🌐 → Clic en "Crear un proyecto" → Nombre: alpha-producciones → Clic "Continuar" → Desactiva Analytics (opcional) → "Crear proyecto"
2 Registrar tu app Web en Firebase ▼

Dentro de tu proyecto Firebase:

⚙️ Clic en el ícono </> Web → Nombre: alpha-cotizador → "Registrar app" → Copia el objeto firebaseConfig que aparece → "Continuar a la consola"

El firebaseConfig se ve así:

const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "alpha-producciones.firebaseapp.com",
  databaseURL: "https://alpha-producciones-default-rtdb.firebaseio.com",
  projectId: "alpha-producciones",
  storageBucket: "alpha-producciones.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};
3 Activar Realtime Database ▼

En el menú izquierdo de Firebase Console:

📁 Compilación → "Realtime Database" → "Crear base de datos" → Ubicación: us-central1 → Modo: "Comenzar en modo de prueba" → "Habilitar"

⚠️ El modo de prueba dura 30 días. Después debes configurar reglas de seguridad.

4 Activar Authentication (Email/Password) ▼

En Firebase Console menú izquierdo:

🔐 Compilación → "Authentication" → "Comenzar" → Pestaña "Sign-in method" → "Correo electrónico/contraseña" → Activar → "Guardar"
5 Pegar tu configuración aquí abajo ▼

Copia el firebaseConfig de tu proyecto y pégalo en el campo de abajo:

6 Publicar en GitHub Pages ▼

Para que tu app esté en línea:

1. Ve a github.com → Crea cuenta → "New repository"
2. Nombre: alpha-cotizador · Público ✅
3. Sube tu index.html → "Commit changes"
4. Settings → Pages → Source: main / root → Save
5. URL lista: https://TU-USUARIO.github.io/alpha-cotizador

⚠️ Agrega tu dominio GitHub a Firebase: Console → Authentication → Authorized domains → "Agregar dominio"
